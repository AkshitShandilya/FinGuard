# Prototype

## Overview

The FinGuard AI prototype demonstrates the proposed fraud detection workflow and user interaction with the system.

The prototype focuses on:

- Transaction submission
- Risk assessment
- Fraud detection
- Risk classification
- Analyst review
- Explainable results

## Prototype Stages

1. Transaction submission
2. Feature extraction
3. Fraud detection
4. Risk aggregation
5. Risk classification
6. Analyst review
7. Feedback collection
